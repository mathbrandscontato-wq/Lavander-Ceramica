# Catálogo: contrato mínimo
Integração com CMS **não configurada**. Não armazenar produtos fictícios como conteúdo comercial. Os documentos do CMS deverão ter IDs estáveis, slugs únicos, taxonomias consistentes e estado de publicação. Preços, estoque, imagens, elegibilidade para personalização e ordem de exibição exigem aprovação da proprietária.

Adotar Sanity somente após validação da conta, limites, custos, permissões e fluxo de publicação. Planejar rebuild automático por webhook assinado quando houver conteúdo aprovado.
